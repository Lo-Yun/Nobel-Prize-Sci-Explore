## 熱力學假說與摺疊漏斗

安芬森的**熱力學假說**指出，在生理條件下，天然結構對應自由能的全域極小值：

<div class="math">ΔG<sub>fold</sub> = G<sub>native</sub> − G<sub>unfolded</sub> ≈ −20 到 −60 kJ/mol</div>

這個差距其實很小，是焓（氫鍵、凡得瓦力、鹽橋）與熵（主鏈構形熵的損失、疏水效應帶來的溶劑熵增加）之間精細抵銷後的結果。

列文索爾悖論的答案是**摺疊漏斗**：能量地形並不是一片平坦、只在某處有一個深洞的高爾夫球場，而是整體向天然結構傾斜的漏斗。演化挑選出「最小挫折」的序列，使得局部有利的接觸，大多也和天然結構一致。這和 2024 年物理學獎中，霍普菲爾德網路把記憶設計成能量極小值的想法，是同一套語言。

## HP 晶格模型

狄爾等人提出的 HP 模型，把 20 種胺基酸簡化為疏水（H）與極性（P）兩類，鏈放在晶格上，並且不能自我交叉（自迴避行走）：

<div class="math">E = ε · Σ<sub>⟨i,j⟩, |i−j|>1</sub> δ<sub>H,i</sub> δ<sub>H,j</sub>，　ε = −1</div>

即使是這麼簡化的模型，在二維正方晶格上求最低能量構形也是 NP 困難問題。構形數量隨長度大致以 μ<sup>N</sup> 成長，其中 μ ≈ 2.638（二維正方晶格的連通常數）。

:::互動 hp-fold
這是 Unger 與 Moult 的 20 顆基準序列，已知最低能量為 −9。電腦使用樞紐旋轉與轉角翻轉兩種移動，搭配梅特羅波利斯接受準則，以及線性降溫的模擬退火。多跑幾次：能量曲線常常卡在 −7 或 −8 的局部極小值，這正是粗糙能量地形的特徵。
:::

## 共同演化：從序列統計到接觸圖

若位置 i 與 j 在結構中接觸，其中一個發生突變後，另一個也會受到補償突變的選擇壓力。對多重序列比對中的第 i、j 欄計算**相互資訊**：

<div class="math">MI<sub>ij</sub> = Σ<sub>a,b</sub> f<sub>ij</sub>(a,b) · ln [ f<sub>ij</sub>(a,b) / ( f<sub>i</sub>(a) f<sub>j</sub>(b) ) ]</div>

MI 有兩個主要問題：

1. **系統發生偏差與欄位熵**：變異程度高的欄位，MI 普遍偏高。平均乘積校正 APC<sub>ij</sub> = MI<sub>i·</sub> MI<sub>·j</sub> / MI<sub>··</sub> 可以扣除這部分背景。
2. **間接耦合**：若 i–j 和 j–k 都有接觸，i 與 k 之間也會出現相關，但它們未必真的接觸。直接耦合分析（DCA）用最大熵模型（波茲曼形式的 Potts 模型）來分離直接與間接效應：

<div class="math">P(a<sub>1</sub>, …, a<sub>L</sub>) = (1/Z) exp[ Σ<sub>i</sub> h<sub>i</sub>(a<sub>i</sub>) + Σ<sub>i&lt;j</sub> J<sub>ij</sub>(a<sub>i</sub>, a<sub>j</sub>) ]</div>

這正是波茲曼機的形式。2011 年前後，Marks 等人證明，僅用 DCA 預測的接觸，就足以折出許多蛋白質的大致結構。

:::互動 coevolution
這個模擬家族中，位置 i 與 15−i 互相接觸，並以帶電互補（K–E、R–D）或疏水配對的方式共同演化，另有 12% 的隨機突變作為雜訊。切換 APC 校正，並降低序列數量，觀察精確度如何下降。在實際應用中，有效序列數通常需要達到數百到數千條。
:::

## AlphaFold2 的架構

AlphaFold2 是一個端到端的可微分模型，輸入序列、MSA 與（可選的）模板，直接輸出所有重原子的三維座標：

1. **兩種表示**：MSA 表示（N<sub>seq</sub> × L × c）與成對表示（L × L × c）。後者可以視為隱含的「距離與方向圖」。
2. **Evoformer**（48 個區塊）：在 MSA 上做逐列與逐欄的注意力；用外積平均把 MSA 的資訊寫入成對表示；在成對表示上做**三角形乘法更新**與三角形注意力，鼓勵 i–j、j–k、i–k 三邊的幾何一致性（滿足三角不等式）。
3. **結構模組**：把每個殘基視為一個剛體座標系（旋轉加平移），用**不變點注意力**（IPA）迭代更新。IPA 對整體旋轉與平移保持不變。
4. **回收**：把輸出再餵回網路，重複 3 次。
5. **損失與信心**：主要損失是 FAPE（以每個局部座標系衡量的原子位置誤差），並輸出每個殘基的信心分數 **pLDDT**（0–100）與預測對齊誤差 PAE。

在 CASP14，AlphaFold2 主鏈預測的中位數誤差約 0.96 Å（Cα RMSD₉₅），而次佳的方法約為 2.8 Å。

## 局限

- **動態與構形變化**：AlphaFold 通常預測單一主要構形，難以描述摺疊路徑、別構變化與內在無序區域（這些區域的 pLDDT 通常很低）。
- **複合體與配體**：AlphaFold-Multimer、AlphaFold 3（2024）與 RoseTTAFold All-Atom 擴展到蛋白質複合體、核酸、小分子與修飾，但準確度因系統而異。
- **單點突變的效應**：模型對「一個胺基酸的改變會如何影響穩定性」仍然不夠敏感。
- **MSA 不足**：缺乏同源序列的孤兒蛋白質與人工設計的序列，預測準確度通常較低。

## 計算蛋白質設計

**逆向摺疊**的目標，是在給定主鏈結構 X 的情況下，找出序列 s，使得：

<div class="math">s* = argmin<sub>s</sub> E(s, X)，　同時讓 X 成為該序列能量地形上明顯的全域極小值</div>

前半部是**正向設計**（讓目標結構穩定），後半部是**負向設計**（讓其他競爭結構不穩定），後者更難。貝克團隊的演進：

- **Rosetta**（1990 年代末起）：片段組裝、蒙地卡羅搜尋與統計／物理混合的能量函數。
- **Top7**（2003）：自然界不存在的摺疊方式，實驗結構與設計模型的誤差約 1.2 Å。
- **功能性設計**：病毒結合蛋白、酵素、自我組裝的奈米籠，以及以設計的奈米顆粒為基礎的新冠疫苗 SKYCovione（2022 年在南韓獲准）。
- **深度學習設計**：ProteinMPNN（以神經網路做逆向摺疊）、RFdiffusion（以擴散模型從雜訊生成主鏈），再用 AlphaFold 或 RoseTTAFold 做「預測驗證」。

:::互動 hp-fold design
在 HP 模型中做逆向摺疊：目標結構固定，搜尋序列。成功時，電腦常會找到其他簡併的最低能量構形，這就是負向設計要解決的問題。試著調整 H 的位置，減少競爭構形的數量。
:::

## 小測驗

:::測驗
- 問題: 摺疊漏斗模型如何解釋列文索爾悖論？
  選項: [能量地形整體朝天然結構傾斜，局部有利的接觸大多與天然結構一致，不需要隨機搜尋所有構形, 蛋白質會先試完所有構形, 蛋白質摺疊不受能量影響]
  答案: 0
  解說: 演化選出的序列具有「最小挫折」，使摺疊能沿著漏斗快速下降。
- 問題: 為什麼單純的相互資訊會高估某些不接觸位置之間的關聯？
  選項: [間接耦合（i–j、j–k 接觸會讓 i–k 也相關）以及系統發生偏差, MI 永遠是負的, 因為胺基酸只有 20 種]
  答案: 0
  解說: DCA 的 Potts 模型與 APC 校正，就是為了分離直接耦合並扣除背景。
- 問題: AlphaFold2 的三角形更新，主要是為了確保什麼？
  選項: [成對表示中的距離關係在幾何上自洽，例如滿足三角不等式, 讓訓練更快, 減少參數數量]
  答案: 0
  解說: 如果 i–j 和 j–k 都很近，i–k 也不可能太遠，三角形更新把這種約束帶進網路。
- 問題: 蛋白質設計中的「負向設計」是什麼意思？
  選項: [讓競爭的錯誤結構變得不穩定，使目標結構成為唯一的明顯極小值, 讓蛋白質帶負電, 刪除不需要的胺基酸]
  答案: 0
  解說: 只讓目標很穩定還不夠，還必須確保序列不會摺成其他同樣穩定的結構。
:::
