## 讓喉嚨長出一層膜的可怕疾病

:::對話 小諾 思考
一百多年前，有一種病叫「白喉」。生病的小朋友喉嚨裡會長出一層灰白色的膜，讓人呼吸困難，很多孩子因此失去生命。
:::

白喉是一種細菌造成的。可怕的不只是細菌本身，而是細菌放出來的**毒素**。毒素會跟著血液跑到全身，傷害心臟和神經。

## 認識今天的主角

:::對話 馮・貝林 預設
我是馮・貝林，是德國的軍醫和科學家。我一直在想：有沒有辦法對付細菌放出來的毒素？
:::

:::對話 北里柴三郎 開心
我是北里柴三郎，從日本到德國學習。我和馮・貝林一起做實驗，研究破傷風和白喉。
:::

:::對話 阿駿 開心
我是阿駿，一匹馬！我的血液裡有一種寶貝，可以幫助生病的小朋友喔。
:::

## 血液裡的祕密武器

馮・貝林和北里柴三郎做了一個實驗：

1. 先給動物打一點點毒素。毒素很少，動物不會生病。
2. 過一陣子再打多一點。動物的身體會慢慢做出能**中和毒素**的東西，叫做**抗毒素**。
3. 把這隻動物的血液中，淡黃色、透明的部分（**血清**）取出來，打進另一隻生病的動物身上。
4. 結果，生病的動物好起來了！

:::對話 小Y 預設
抗毒素就是我們抗體！我們會抓住毒素，讓它沒辦法去傷害細胞。
:::

這就是**血清療法**：把一隻動物身體做出來的抗毒素，「借」給另一個生病的身體。後來，科學家用體型大的**馬**來製造大量血清，因為馬的血液很多，又很溫和。

## 動手試試：做血清、救病童

:::互動 serum-therapy
先在上面的時間軸點一點，替阿駿安排打針的日子，看看抗毒素什麼時候夠多。再到下面，決定生病的孩子要多早打血清。
:::

:::對話 阿駿 預設
發現了嗎？第二次、第三次打針後，我的身體做抗毒素做得又快又多！還有，血清要越早打越好，因為毒素一旦鑽進細胞，抗毒素就抓不到了。
:::

## 這個發現改變了什麼？

- **救了無數孩子**：血清療法讓白喉的死亡率大幅下降。
- **第一座諾貝爾生理學或醫學獎**：1901 年，馮・貝林得到了第一屆諾貝爾生理學或醫學獎。
- **今天還在用**：被毒蛇咬傷時打的「抗蛇毒血清」，用的也是同樣的原理，臺灣的抗蛇毒血清就是用馬製造的。

:::小知識 雪地裡的狗拉雪橇接力
1925 年冬天，美國阿拉斯加的小鎮諾姆爆發白喉。暴風雪讓飛機無法起飛，人們用狗拉雪橇接力，花了大約五天半，把血清送到一千公里外的小鎮。帶頭的雪橇狗還被做成了銅像。
:::

## 小測驗

:::測驗
- 問題: 白喉最可怕的地方是什麼？
  選項: [細菌放出的毒素會傷害全身, 會讓人變胖, 會讓頭髮變白]
  答案: 0
  解說: 白喉桿菌放出的毒素會隨著血液到處跑，傷害心臟和神經。
- 問題: 血清療法是怎麼做的？
  選項: [把動物身體做出來的抗毒素，借給生病的人, 讓病人吃很多青菜, 把細菌打進病人身體]
  答案: 0
  解說: 先讓動物產生抗毒素，再把含有抗毒素的血清打給病人。
- 問題: 為什麼血清要越早打越好？
  選項: [毒素鑽進細胞以後，抗毒素就抓不到了, 血清放久會變甜, 晚上醫院會關門]
  答案: 0
  解說: 抗毒素只能中和還在血液裡的毒素，所以要搶在毒素鑽進細胞之前。
:::
