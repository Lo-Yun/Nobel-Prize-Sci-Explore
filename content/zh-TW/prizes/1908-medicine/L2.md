## 兩千年的謎題：發炎是什麼？

西元一世紀，羅馬學者塞爾蘇斯描述了發炎的四大徵象：**紅、熱、腫、痛**。後來又加上第五個：**功能喪失**，通常認為是十九世紀的病理學家魏修補上的。

但發炎到底是什麼？十九世紀的主流看法認為，發炎是組織受到刺激後的**損傷**，聚集的白血球甚至可能幫助細菌散播。1867 年，病理學家孔漢在青蛙的腸繫膜上，親眼看到白血球**從血管壁鑽出來**，往受傷的組織移動。白血球為什麼要這麼做？當時沒有人知道答案。

:::對話 小諾 思考
在這個時期，免疫學正分成兩派：一派認為保護身體的是**細胞**，另一派認為是**血液中的物質**。1908 年的諾貝爾獎，同時頒給了兩派的代表人物。
:::

## 梅契尼可夫：會吃東西的細胞

梅契尼可夫原本是研究無脊椎動物胚胎發育的動物學家。他注意到，海綿、水母這些簡單動物的體內，有些細胞會像變形蟲一樣**把食物吞進去消化**。

:::時間軸
- 時間: 1882
  事件: 在西西里島墨西拿，把玫瑰刺插入透明的海星幼體；隔天，大量移動細胞聚集在刺的周圍。
- 時間: 1883
  事件: 發表吞噬作用的理論，並採用動物學家克勞斯建議的名稱「吞噬細胞」（phagocyte，希臘文「吃的細胞」）。
- 時間: 1884
  事件: 觀察水蚤感染一種真菌孢子：吞噬細胞贏了，水蚤存活；孢子贏了，水蚤死亡。
- 時間: 1888
  事件: 應巴斯德邀請，加入剛成立的巴黎巴斯德研究所。
- 時間: 1892
  事件: 出版《發炎的比較病理學講義》，主張發炎是以吞噬細胞為中心的防禦反應。
- 時間: 1908
  事件: 與艾利希共同獲得諾貝爾生理學或醫學獎。
:::

梅契尼可夫的核心主張是：**發炎是身體的保護反應，而不是單純的損傷**。血管擴張與滲漏，是為了把吞噬細胞送到戰場；白血球穿出血管，是為了吞噬入侵者。他也區分了兩類吞噬細胞：體型小、反應快的「小噬細胞」（今天的嗜中性球），以及體型大、負責清理的「巨噬細胞」。

## 動手試試：發炎的過程

:::互動 inflammation-sim
插入帶細菌的刺之後，紫色是受傷組織與細菌放出的「訊號」。觀察血管如何變寬（紅、熱）、組織如何積水（腫），以及白血球如何沿著訊號越來越濃的方向前進（趨化作用）。調快細菌的分裂速度，看看白血球還追不追得上。
:::

用今天的語言來說，發炎大致分成幾個步驟：

1. **偵測**：受傷的細胞和細菌放出訊號分子。
2. **血管反應**：小血管擴張，血流增加（紅、熱）；血管壁變得容易滲漏，血漿滲入組織（腫）；訊號分子刺激神經（痛）。
3. **白血球招募**：白血球在血管壁上「滾動」、黏住，再從血管壁的縫隙鑽出去。
4. **趨化與吞噬**：白血球順著訊號濃度前進，找到細菌後吞進去分解。
5. **消退與修復**：敵人清除後，巨噬細胞清理戰場，發炎主動「關機」，組織開始修復。

## 艾利希：染料、受體與魔法子彈

艾利希是醫生，也是化學染料的高手。他在學生時代就用苯胺染料區分出不同的白血球：容易被酸性染料染色的**嗜酸性球**、被鹼性染料染色的**嗜鹼性球**、被中性混合染料染色的**嗜中性球**，還發現了**肥大細胞**。這些細胞，今天都是發炎研究的主角。

1890 年代，馮・貝林發現白喉抗毒素可以治病，但每一批血清的效力差異很大。艾利希設計了一套精確的方法，替抗毒素訂定標準單位，讓血清療法能安全地普及。

為了解釋抗毒素從哪裡來，他在 1897 年提出**側鏈理論**：

- 細胞表面有各種化學結構的「側鏈」，原本用來抓取養分。
- 毒素剛好能和某種側鏈結合，就像鑰匙插進鎖。
- 被毒素佔住的側鏈失去作用，細胞於是**過量製造**同一種側鏈。
- 多餘的側鏈脫落到血液中，就成了**抗毒素**，能在毒素碰到細胞之前把它中和。

:::互動 side-chain
先注射一種毒素，觀察細胞的反應；等血液中出現抗毒素後，再注射同一種毒素，比較兩次有什麼不同。
:::

側鏈理論的細節後來被修正了：今天我們知道，抗體是由 B 細胞製造，而且每個 B 細胞只製造一種抗體。但艾利希提出的**受體**與**專一結合**的概念，到今天仍是免疫學與藥理學的基礎。他說過一句名言：「物質不結合，就不起作用。」

艾利希後來想找出只攻擊病菌、不傷害人體的化學物質，他稱之為**魔法子彈**，並創造了「化學治療」這個詞。1909 年，他和日本學者秦佐八郎找到了治療梅毒的灑爾佛散（編號 606 的化合物）。

## 細胞派與體液派的和解

1903 年，英國的賴特與道格拉斯發現，血清中有某些物質會「調味」細菌，讓吞噬細胞更容易吞食，他們稱之為**調理素**。這正好把兩派連在一起：**抗體抓住並標記敵人，吞噬細胞負責吃掉。**在上面的發炎模擬裡打開「抗體標記」，就能看到這個效果。

## 小測驗

:::測驗
- 問題: 在梅契尼可夫之前，很多人怎麼看待發炎？
  選項: [認為發炎主要是組織受到刺激後的損傷, 認為發炎是身體在吃東西, 認為發炎和白血球無關]
  答案: 0
  解說: 梅契尼可夫的貢獻，是把發炎重新解讀為以吞噬細胞為中心的防禦反應。
- 問題: 發炎時的「腫」，主要是怎麼造成的？
  選項: [血管壁變得容易滲漏，血漿滲入組織, 骨頭變大, 細菌太多擠在一起]
  答案: 0
  解說: 血管通透性增加，液體和蛋白質滲入組織間隙，就會腫起來。
- 問題: 艾利希的側鏈理論中，抗毒素是從哪裡來的？
  選項: [細胞過量製造、脫落到血液中的側鏈, 毒素自己變成的, 從食物吃進來的]
  答案: 0
  解說: 細胞的側鏈被毒素佔住後，會補做更多，多餘的脫落到血液中，成為抗毒素。
- 問題: 「調理作用」怎麼把細胞派和體液派連在一起？
  選項: [抗體標記細菌，讓吞噬細胞更容易吞食, 吞噬細胞會製造毒素, 抗體會殺死白血球]
  答案: 0
  解說: 兩種機制互相合作：體液中的抗體負責辨認與標記，細胞負責清除。
:::
