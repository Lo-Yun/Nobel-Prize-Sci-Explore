## 影子疊影子的困境

傳統 X 光片是一張**投影**：X 光沿著直線穿過身體，底片記錄的是整條路徑上衰減的總和。前後重疊的組織全部擠在同一個位置，而且軟組織之間的差異（例如腦灰質和白質只差不到 1%）會被頭骨的強烈衰減完全蓋住。

在 CT 出現之前，要看腦部結構，有一種方法叫{{氣腦造影|從腰椎抽出腦脊髓液、灌入空氣，讓腦室在 X 光片上顯影。過程非常痛苦，也有風險。}}。醫生迫切需要更好的方法。

## 兩個人、兩條路、同一個答案

:::時間軸
- 時間: 1956 年
  事件: 物理學家柯馬克在南非開普敦的醫院兼差，負責放射治療的劑量計算。他發現醫院假設人體是均勻的，於是開始思考：能不能從外面量測到的 X 光，算出身體內部每一點的衰減？
- 時間: 1963–1964 年
  事件: 柯馬克在美國發表兩篇論文，提出數學方法並用鋁和木頭做的模型驗證。幾乎沒有人注意到。
- 時間: 1967 年起
  事件: 英國 EMI 公司的工程師杭斯菲爾德，在不知道柯馬克研究的情況下，獨立構想並開始製作原型機。
- 時間: 1971 年 10 月 1 日
  事件: 第一台臨床 CT 在倫敦的阿特金森・莫利醫院掃描了第一位病人，發現腦中的腫瘤。
- 時間: 1979 年
  事件: 柯馬克和杭斯菲爾德共同獲得諾貝爾生理學或醫學獎。
:::

:::對話 柯馬克 預設
我的論文發表之後，幾乎沒有人回應。我記得唯一一封來索取論文的信，來自瑞士的雪崩研究中心。他們想知道積雪內部的密度分布。
:::

## CT 怎麼「看」到切面？

想像把身體的一個橫切面，分成許多小方格。每個方格有一個未知數：它讓 X 光衰減多少。

1. **一條射線，一個方程式**：X 光管和偵測器分別在身體兩側，每一條射線量到的，是它經過的所有方格衰減的**總和**。
2. **繞一圈，收集上萬個方程式**：X 光管和偵測器一起繞著身體旋轉，從幾百個角度、每個角度幾百條射線，收集足夠的資料。把所有角度的投影排在一起，就是一張{{正弦圖|橫軸是偵測器的位置，縱軸是角度。身體裡的每一個點，在圖上都會畫出一條正弦曲線，因此得名。}}。
3. **電腦解謎**：最直接的想法是**反投影**，把每個角度的投影沿原來的方向「抹」回切面上。疊加之後，有東西的地方會比較亮，但整張影像會帶著一層模糊的光暈。
4. **濾波**：先把每個投影做「銳化」處理（濾波），再反投影，模糊就會互相抵消，得到清楚的影像。這就是現在 CT 最常用的**濾波反投影法**。

這是一個簡化的「胸部切面」：兩側是充滿空氣的肺，下方是脊椎，左肺裡藏著一個小腫瘤。從 1 個角度開始，慢慢增加角度，再比較有沒有濾波的差別。

## 亨氏單位：給每個方格打分數

CT 影像的每一個點，都用**亨氏單位**（Hounsfield Unit, HU）表示衰減的程度，以水為 0、空氣為 −1000：

| 組織 | 約略 HU |
|---|---|
| 空氣 | −1000 |
| 肺 | −900 到 −500 |
| 脂肪 | −100 左右 |
| 水 | 0 |
| 軟組織、肌肉 | +20 到 +60 |
| 骨頭 | +300 到 +1900 |

因為每個方格都是單獨計算的，CT 能分辨傳統 X 光片看不出來的細微密度差，例如腦出血和正常腦組織。

:::小知識 輻射劑量
一次胸部 CT 的有效劑量，大約是一張胸部 X 光片的數十到數百倍。CT 是非常有價值的檢查，但醫生會評估利弊，只在必要時安排；兒童更需要謹慎。
:::

## 小測驗

:::測驗
- 問題: 一般 X 光片無法清楚分辨腦組織，主要原因是什麼？
  選項: [X 光無法穿過頭骨, 整條路徑的衰減疊在一起，頭骨的衰減蓋過了腦組織間微小的差異, 腦組織會發光]
  答案: 1
  解說: 投影把前後的結構疊在一起，而腦組織之間的差異只有不到 1%。
- 問題: CT 中，一條 X 光射線量到的數值代表什麼？
  選項: [射線經過的所有小方格衰減的總和, 單一方格的衰減, 病人的體重]
  答案: 0
  解說: 每條射線提供一個「總和」方程式，要用許多射線一起解出各個方格的值。
- 問題: 單純反投影的影像有什麼問題？濾波的作用是什麼？
  選項: [影像太暗；濾波讓它變亮, 影像帶有模糊光暈；濾波可以抵消模糊、得到清楚的影像, 影像是彩色的；濾波讓它變黑白]
  答案: 1
  解說: 反投影會把每個點的值抹成放射狀的光暈；濾波反投影先銳化投影，就能把這些光暈抵消。
- 問題: 水的亨氏單位是多少？
  選項: [−1000, 0, +1000]
  答案: 1
  解說: 亨氏單位以水為 0、空氣為 −1000 來定義。
:::
