## X 光照片有一個小問題

:::對話 小諾 思考
X 光照片可以看到骨頭，好厲害！可是，如果骨頭前面和後面都有東西，會怎麼樣呢？
:::

想像你把一整條吐司從正面拍照，再把所有切片「疊」在同一張照片裡。前面的葡萄乾、後面的葡萄乾，全部擠在一起，根本分不出誰在前、誰在後。

一般的 X 光照片就是這樣：身體前前後後的東西，全部**疊成一張影子**。腦袋外面又有一層硬硬的頭骨，裡面軟軟的大腦幾乎看不清楚。

## 從很多方向照，再交給電腦

兩位科學家想到的方法很像在玩猜謎：

1. 讓 X 光從**前面**照過去，記下影子。
2. 再從**旁邊**、**斜斜的方向**……繞著身體一圈，從幾百個方向都照一次。
3. 每一張影子都只知道「這一條線上，總共擋住了多少 X 光」。
4. 把所有線索交給**電腦**，電腦就能算出：每一個小格子裡，到底是骨頭、肌肉，還是空氣。

最後得到的影像，就像把身體**切成一片一片的吐司**，可以一片一片仔細看，而且不用真的開刀！

:::對話 小X 開心
我們 X 光小精靈要從四面八方跑過去好多次。每一次都偷偷記下「一路上被擋了多少」，電腦再把這些線索拼起來！
:::

## 動手試試：神秘盒子

:::互動 ct-shadows
盒子裡藏著鑰匙。從不同方向照 X 光，看影子落在哪裡，再點格子放上 📍。猜好了就打開盒子對答案！
:::

## 這個發現改變了什麼？

- **看見大腦**：醫生第一次能清楚看到腦袋裡面有沒有出血或腫瘤。1971 年，第一位病人就是用這台機器，在腦中找到了腫瘤。
- **急診的好幫手**：車禍或中風的病人，幾分鐘內就能知道身體裡發生了什麼事。
- **兩位得主一起領獎**：1979 年，他們一起得到諾貝爾生理學或醫學獎。有趣的是，兩個人都不是醫生！

:::對話 小諾 開心
不過，電腦斷層要拍很多次 X 光，所以照射的量比一張 X 光照片多很多。醫生只會在真的需要的時候才安排喔！
:::

## 小測驗

:::測驗
- 問題: 一般 X 光照片有什麼問題？
  選項: [顏色太多, 身體前後的東西全部疊在一起, 照不到骨頭]
  答案: 1
  解說: 一張 X 光照片會把整條路徑上的東西疊成一個影子，分不出前後。
- 問題: 電腦斷層掃描是怎麼做的？
  選項: [從很多方向拍 X 光，再讓電腦算出切片影像, 真的把身體切開, 用放大鏡看身體]
  答案: 0
  解說: 從四面八方拍攝，再用電腦計算，就能得到一片一片的影像。
- 問題: 在神秘盒子遊戲裡，為什麼要從很多方向照？
  選項: [因為比較好玩, 一個方向只知道東西在哪一排，要多個方向交叉才能找到位置, 因為盒子會轉]
  答案: 1
  解說: 每個方向的影子只給一部分線索，交叉起來才能確定位置，CT 也是一樣的道理。
:::
