## 從衰減到線積分

單能 X 光沿直線 ℓ 穿過衰減係數分布為 μ(x, y) 的物體時，依照比爾–朗伯定律：

<div class="math">I = I<sub>0</sub> · exp( −∫<sub>ℓ</sub> μ ds )　⇒　p = −ln(I / I<sub>0</sub>) = ∫<sub>ℓ</sub> μ(x, y) ds</div>

取對數之後，每一次量測就是 μ 沿一條直線的**線積分**。用角度 θ 與偵測器座標 t 參數化直線 x cosθ + y sinθ = t，所有線積分的集合就是**拉東轉換**：

<div class="math">p<sub>θ</sub>(t) = ∬ μ(x, y) · δ(x cosθ + y sinθ − t) dx dy</div>

拉東在 1917 年已經證明，只要知道所有 θ ∈ [0, π) 的 p<sub>θ</sub>(t)，就能唯一決定 μ。柯馬克在 1963 年獨立推導出等價的反演公式，當時並不知道拉東的工作。

## 傅立葉切片定理

對 p<sub>θ</sub>(t) 沿 t 做一維傅立葉轉換，會得到 μ 的二維傅立葉轉換在同一角度上的一條「切片」：

<div class="math">P<sub>θ</sub>(ω) = M(ω cosθ, ω sinθ)</div>

所以，收集足夠多角度的投影，就等於用放射狀的線填滿頻率平面，再做二維反傅立葉轉換即可。但在極座標下積分時，會出現一個面積元素 |ω|：

<div class="math">μ(x, y) = ∫<sub>0</sub><sup>π</sup> [ ∫ P<sub>θ</sub>(ω) · |ω| · e<sup>2πiωt</sup> dω ]<sub>t = x cosθ + y sinθ</sub> dθ</div>

方括號內的運算，就是把每個投影先乘上 |ω|（**斜坡濾波器**），再轉回空間域；外層的積分則是**反投影**。這就是**濾波反投影**（FBP）。

如果省略 |ω|，直接反投影，得到的是 μ 與 1/r 的摺積：每個點都被抹成放射狀的光暈。這正是互動元件中「無濾波」影像模糊的原因。

## 動手試試：FBP 與取樣

:::互動 ct-reconstruct
重建使用 96 × 96 像素的假體，以像素驅動的方式計算投影，再以空間域的 Ram-Lak 濾波核（h(0) = 1/4，h(奇數 n) = −1/(π²n²)）做濾波反投影。觀察角度數很少時的放射狀條紋，並比較均方根誤差。
:::

**取樣條件**：若影像寬度有 N 個像素，每個投影約需 N 個偵測器取樣。要讓頻率平面最外圈的角向取樣間隔，與徑向取樣間隔相當，大約需要 πN/2 個角度。角度不足時，就會出現互動元件中看到的放射狀條紋偽影。

## 杭斯菲爾德的工程解法

杭斯菲爾德並沒有使用 FBP。他採用的是**代數重建法**（ART）：把切面離散成 n × n 的未知數，每條射線是一個線性方程式，再用迭代的方式逐條修正。EMI 第一台臨床機（1971）以 80 × 80 的矩陣成像。資料收集與計算都需要好幾分鐘，所以病人的頭部要固定在水袋中。

迭代法在 1970 年代因為運算量太大，逐漸被 FBP 取代。近年來，隨著運算能力提升，加上降低劑量的需求，**迭代重建**和深度學習重建又重新成為主流。

## 亨氏單位與射束硬化

臨床 CT 以水和空氣為基準，把 μ 線性換算成整數：

<div class="math">HU = 1000 × ( μ − μ<sub>水</sub> ) / ( μ<sub>水</sub> − μ<sub>空氣</sub> )</div>

真實的 X 光管會發出連續譜（見 1901 年物理學獎 L3）。低能光子在穿透過程中先被吸收，使穿出的射束平均能量提高，這就是**射束硬化**。因此，−ln(I/I₀) 並不是 μ 的線性積分，會在骨頭之間產生暗帶，並讓均勻物體的中心看起來比較暗（杯狀偽影）。實務上的處理方式包括：使用鋁或銅濾片預先硬化射束、對水做多項式校正，以及雙能量 CT。

## 從單切面到現代 CT

- **第三代架構**：X 光管與弧形偵測器陣列一起旋轉，一圈不到 0.3 秒。
- **螺旋 CT**（1989 年起）：病床連續移動，X 光管連續旋轉，短時間內就能取得整段身體的立體資料。
- **多排偵測器**：一次旋轉可涵蓋數公分到 16 公分，能捕捉心臟跳動的瞬間。
- **錐狀射束 CT**：牙科與術中影像常用，使用 FDK 等三維重建演算法。

## 小測驗

:::測驗
- 問題: 為什麼 CT 的原始資料要先取 −ln(I/I₀)？
  選項: [讓數字變小, 把指數衰減轉成衰減係數的線積分，問題才變成線性, 去除雜訊]
  答案: 1
  解說: 比爾–朗伯定律是指數關係；取對數後，量測值才等於 ∫μ ds，可以使用線性的重建方法。
- 問題: 傅立葉切片定理說的是什麼？
  選項: [投影的一維傅立葉轉換，等於物體二維傅立葉轉換在同一角度上的切片, 投影越多雜訊越大, 切片厚度與頻率成正比]
  答案: 0
  解說: 這是 FBP 與直接傅立葉重建法的數學基礎。
- 問題: 濾波反投影中的斜坡濾波器 |ω| 是從哪裡來的？
  選項: [為了去除雜訊而人為加上, 從極座標換回直角座標時的面積元素（Jacobian）, 來自 X 光管的能譜]
  答案: 1
  解說: 在極座標下對頻率平面積分，dω_x dω_y = |ω| dω dθ。
- 問題: 影像矩陣是 256 × 256 時，依取樣準則大約需要多少個投影角度？
  選項: [約 30 個, 約 400 個, 約 10000 個]
  答案: 1
  解說: πN/2 ≈ 3.14 × 256 / 2 ≈ 402。
:::
