## 你能看到自己的骨頭嗎？

:::對話 小諾 預設
嗨！我是小諾。我們先來玩個遊戲：把手放在手電筒前面，你看得到裡面的骨頭嗎？
:::

手電筒的光很難穿過我們的手，最多只會讓手指邊緣變得紅紅的。所以一百多年前，大家都覺得：**想看身體裡面，只能把身體打開。**

直到 1895 年的一個晚上，一位叫做倫琴的科學家，發現了一種**看不見、卻能穿過身體**的神秘光線。

## 認識今天的主角

:::對話 倫琴 預設
你好，我是倫琴，在德國的大學當物理老師。我最喜歡在實驗室裡一個人安安靜靜地做實驗。
:::

:::對話 小X 開心
我是小X！我是一顆「X 光小精靈」。我跑得跟光一樣快，可是你的眼睛看不見我喔！
:::

:::對話 小諾 思考
為什麼叫「X」呢？
:::

:::對話 倫琴 開心
因為我發現它的時候，完全不知道它是什麼。數學裡常用 X 代表「還不知道的東西」，所以我就叫它 X 光！
:::

## 黑暗中發光的祕密

倫琴的實驗室裡，有一根特別的玻璃管。通電以後，管子裡會發出淡淡的光。

那天晚上，他做了一件奇怪的事：**用黑色厚紙把玻璃管整個包起來**，再把房間的燈關掉，確認一點光都漏不出來。

:::對話 小諾 驚訝
可是，桌子另一邊的一塊小板子，竟然亮起來了！
:::

那塊板子上塗了一種特殊的藥粉，被某些光照到就會發出黃綠色的光。可是玻璃管明明被包得緊緊的呀！倫琴想：**一定有某種看不見的光，穿過了黑紙，跑到板子上。**

接下來好幾個星期，倫琴幾乎都待在實驗室裡。他拿書、木板、金屬片擋在中間，一樣一樣試。最驚人的是，當他把手伸到中間，板子上竟然出現了**自己手骨的影子**！

:::小知識 第一張人體 X 光照片
1895 年 12 月，倫琴請太太把手放在照相底片上，拍下了第一張人體 X 光照片。照片裡看得到她手指的骨頭，還有手上那枚戒指。
:::

## 動手試試：X 光透視鏡

:::互動 xray-lens
拖曳透視鏡，找出藏起來的東西。看看什麼東西最亮？
:::

:::對話 小X 預設
我可以輕鬆穿過皮膚和肌肉，可是遇到骨頭就比較難穿過，遇到金屬幾乎完全被擋住。被擋住的地方，在 X 光照片上就會變成白色的影子！
:::

## 這個發現改變了什麼？

- **醫生可以「看見」骨折**：不用開刀，就知道骨頭哪裡斷了。
- **檢查牙齒**：牙醫用 X 光看牙齒裡面有沒有蛀洞。
- **機場安檢**：行李箱不用打開，就能看到裡面裝了什麼。

倫琴因為這個發現，在 1901 年得到了**史上第一座諾貝爾物理學獎**。他把獎金捐給了自己工作的大學，也沒有申請專利。他希望 X 光可以讓全世界的人自由使用。

:::對話 小諾 開心
不過要記得，X 光的能量很強，照太多對身體不好。所以照 X 光的時候，醫生只會照需要的部位，時間也非常短。
:::

## 小測驗

:::測驗
- 問題: 倫琴為什麼把新的光線叫做「X 光」？
  選項: [因為形狀像 X, 因為 X 代表「還不知道是什麼」, 因為是第 10 種光]
  答案: 1
  解說: 數學裡常用 X 代表未知數。倫琴當時還不知道這種光是什麼。
- 問題: 在 X 光照片裡，哪一個看起來最白（最亮）？
  選項: [肌肉, 皮膚, 金屬戒指]
  答案: 2
  解說: 金屬最會擋住 X 光，所以在照片上最白。骨頭第二，肌肉和皮膚最容易被穿過。
- 問題: 倫琴發現 X 光時，玻璃管被什麼包住了？
  選項: [黑色厚紙, 透明塑膠, 什麼都沒包]
  答案: 0
  解說: 黑紙擋住了一般的光，可是遠處的板子還是亮了，所以他才知道有一種新的、看不見的光！
:::
