## 一塊不該發亮的螢光幕

1895 年 11 月 8 日傍晚，德國維爾茨堡大學的物理教授倫琴，正在暗房裡研究{{陰極射線|在接近真空的玻璃管兩端加上高電壓，從負極（陰極）射出的一道「射線」。後來才知道它就是一大群高速電子。}}。這在當時是最熱門的研究題目。

他用黑色厚紙板把整根管子包起來，確認沒有任何光漏出來。接著他注意到，大約一公尺外，一塊塗了{{氰亞鉑酸鋇|一種螢光物質，被紫外線或其他射線照到時會發出黃綠色的光。}}的紙屏，竟然隨著管子通電一閃一閃地發亮。

:::對話 小諾 思考
陰極射線在空氣中只能跑幾公分，而且根本穿不出玻璃管和厚紙板。那讓螢光幕發光的到底是什麼？
:::

## 七個星期的祕密實驗

倫琴沒有急著對外宣布。據說接下來的七個星期，他幾乎是吃住都在實驗室裡，一個人有系統地測試這種新射線的性質：

:::時間軸
- 時間: 1895-11-08
  事件: 發現被黑紙包住的陰極射線管會讓遠處的螢光幕發光。
- 時間: 11 月～12 月
  事件: 用書本、木板、鋁、鉛、玻璃等材料測試穿透力，發現**密度越高、越重的物質越能擋住它**。
- 時間: 1895-12-22
  事件: 拍下太太安娜・貝爾塔的手部照片，骨頭和戒指清晰可見，曝光大約 15 分鐘。
- 時間: 1895-12-28
  事件: 提交論文〈論一種新的射線〉（Über eine neue Art von Strahlen）。
- 時間: 1896 年 1 月
  事件: 消息傳遍全世界。短短幾週內，各地醫院開始用 X 光找骨折和體內的子彈。
- 時間: 1901-12-10
  事件: 獲頒史上第一座諾貝爾物理學獎。
:::

他在論文裡記錄了好幾個關鍵發現：

1. 這種射線**不會被磁鐵偏折**。陰極射線會轉彎，所以兩者是不同的東西。
2. 它會讓照相底片感光，所以可以「拍照」。
3. 射線是從**陰極射線撞到玻璃管壁的那一點**發出來的。
4. 他找不到明顯的反射或折射現象，因此無法確定它是什麼，便稱它為 **X 射線**。

## 動手試試：重現倫琴的實驗桌

先通電、關燈，再把不同的東西放到管子和螢光幕之間。也試試看磁鐵！穿透率是依倫琴論文描述的材料與厚度，用現代數據估算的。
:::

:::對話 小X 預設
我其實和可見光是同一家族的，都是{{電磁波|電場和磁場互相帶動、向前傳播的波。可見光、紫外線、無線電波都是電磁波，差別只在波長。}}！只是我的波長非常短，大約只有可見光的幾千分之一到幾萬分之一，所以能量很高，能鑽過很多東西。

## 為什麼骨頭會留下影子？

X 光穿過物體時，有一部分會被吸收或散射掉。被擋掉多少，主要看兩件事：

- **密度**：單位體積裡的原子越多，越容易被擋住。
- **原子有多「重」**：原子序越大（原子核裡的質子越多），擋 X 光的能力越強，而且增加得非常快。

肌肉和脂肪主要由氫、碳、氧這些輕原子組成。骨頭裡有大量的**鈣**和**磷**，原子序比較大，密度也比較高。所以 X 光比較容易穿過肌肉，在骨頭那裡則被擋掉比較多。金屬（例如戒指、鉛）又比骨頭更會擋。

:::小知識 為什麼照片上的骨頭是白的？
倫琴在**螢光幕**上看到的骨頭是「暗的影子」，因為擋掉 X 光的地方螢光幕不亮。可是**照相底片**被 X 光照到會變黑，被骨頭擋住的地方反而保持透明，看起來就是白色的。我們現在熟悉的「黑底白骨」，其實是底片的效果。
:::

## 一個發現，打開了好幾扇門

**醫學**：X 光讓醫生第一次不用開刀就能看見身體內部。後來的電腦斷層掃描（CT），就是從很多角度拍 X 光，再用電腦組合成立體影像。

**科學**：X 光到底是什麼？1912 年，勞厄讓 X 光穿過晶體，得到規則的繞射圖案，證明了 X 光是波長極短的電磁波。很快地，科學家又反過來用 X 光去「看」原子的排列，後來連 DNA 雙螺旋的結構都是靠 X 光照片找出來的。

**代價**：早期大家不知道 X 光的危險。有些研究人員和醫生長時間曝露在 X 光下，造成嚴重灼傷，甚至罹患癌症。這讓人們建立了**輻射防護**的觀念。今天照一張胸部 X 光的劑量很低，大約等於幾天內從大自然接收到的背景輻射。

:::對話 倫琴 開心
我沒有為 X 光申請專利，諾貝爾獎的獎金也捐給了大學。我認為這樣的發現屬於全人類。
:::

## 小測驗

:::測驗
- 問題: 倫琴怎麼確定讓螢光幕發光的不是一般的光？
  選項: [他戴上了墨鏡, 他把陰極射線管用黑紙板完全包住, 他把螢光幕放到另一個房間]
  答案: 1
  解說: 黑紙板擋住了所有可見光和紫外線，螢光幕卻還是發亮，所以一定是某種能穿透紙板的新射線。
- 問題: 哪一個實驗結果可以說明 X 射線和陰極射線是不同的東西？
  選項: [X 射線不會被磁鐵偏折, X 射線會讓螢光幕發光, X 射線看不見]
  答案: 0
  解說: 陰極射線是帶電的電子，會被磁鐵推得轉彎。X 射線不帶電，不受磁鐵影響。
- 問題: 骨頭比肌肉更能擋住 X 光，主要原因是？
  選項: [骨頭的顏色比較白, 骨頭含有鈣、磷這類較重的原子，密度也較高, 骨頭比較硬]
  答案: 1
  解說: X 光被擋掉的程度和原子序、密度有關，跟顏色、硬度無關。
- 問題: 我們熟悉的 X 光片上，骨頭為什麼是白色的？
  選項: [骨頭會發光, 底片被 X 光照到會變黑，骨頭擋住 X 光的地方保持透明, 醫生事後塗上白色]
  答案: 1
  解說: 這是底片的「負片」效果。在倫琴的螢光幕上，骨頭反而是暗的影子。
:::
