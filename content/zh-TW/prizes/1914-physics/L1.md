## X 光到底是什麼？

:::對話 小諾 思考
還記得倫琴發現的 X 光嗎？它能穿過身體、照出骨頭。可是過了十幾年，大家還是不知道：X 光到底是什麼？
:::

有人說，X 光像海浪一樣，是一種「波」。也有人說，X 光是一顆一顆飛得很快的「小子彈」。兩邊吵得很厲害，誰也說服不了誰。

:::對話 小X 預設
其實我自己也不知道我是什麼耶……
:::

## 認識今天的主角

:::對話 勞厄 預設
我是勞厄，在德國慕尼黑的大學研究物理。我很喜歡想問題，尤其是「光」的問題。
:::

:::對話 小晶 開心
我是小晶，是一顆食鹽的小晶體！我身體裡的原子排得整整齊齊，像操場上排隊的同學，一排一排、一列一列，一點都不亂。
:::

## 一個聰明的點子

1912 年的某一天，勞厄聽同事聊到晶體裡的原子排列，突然想到一件事：

:::對話 勞厄 開心
如果 X 光是波，而且它的波長跟原子之間的距離差不多，那麼讓 X 光穿過晶體，原子就會像一面很細很細的紗網，讓 X 光排出特別的圖案！
:::

這就像你透過紗窗或雨傘布看遠處的路燈：會看到路燈旁邊多出好幾個小光點，排成十字形。那是因為光是波，穿過細細的網格時會「轉彎」，再互相疊在一起。這叫做**繞射**。

勞厄請兩位很會做實驗的助手幫忙。他們把 X 光射向一塊藍色的硫酸銅晶體，後面放一張照相底片。

:::對話 小諾 驚訝
底片洗出來了！中間有一個大光點，旁邊還圍著一圈小光點！
:::

這些小光點證明了兩件事：**X 光是一種波**，而且**晶體裡的原子真的排得整整齊齊**。一個實驗，一次解開兩個謎！

:::小知識 用紗窗做實驗
晚上隔著紗窗或很細的布看遠處的燈，就能看到「繞射」的光點。注意：千萬不要用這個方法看太陽！
:::

## 動手試試：晶體光點產生器

:::互動 laue-pattern
左邊是晶體裡的原子，右邊是 X 光留在底片上的光點。把原子排得密一點或鬆一點，再轉一轉晶體，看看光點怎麼變？
:::

:::對話 小晶 預設
發現了嗎？我的原子排得越擠，光點反而散得越開！而且我轉一圈，光點也會跟著轉。科學家就是從光點的樣子，反過來猜出原子是怎麼排的。
:::

## 這個發現改變了什麼？

- **科學家有了「看見原子」的方法**：原子小到用任何顯微鏡都看不到，可是從 X 光的光點，就能推算出原子的排列。
- **找出生命的祕密**：後來，科學家用同樣的方法，找出了 DNA 和很多藥物分子的形狀。
- **勞厄得到 1914 年的諾貝爾物理學獎**，那時距離實驗只過了兩年。

:::對話 小諾 開心
還有一個故事：勞厄反對當時德國的納粹政府，他把諾貝爾金牌寄放在丹麥的朋友那裡保管。後來德軍打進丹麥，如果獎牌被找到，勞厄會有危險。朋友就把金牌泡在一種特殊的強酸裡溶解，裝在瓶子裡放在架子上，誰也沒發現。戰爭結束後，再把金子提煉出來，重新做成一面新的獎牌！
:::

## 小測驗

:::測驗
- 問題: 勞厄的實驗證明了 X 光是什麼？
  選項: [一種波, 一種小石頭, 一種聲音]
  答案: 0
  解說: X 光穿過晶體後排出光點圖案，這是「波」才會有的繞射現象。
- 問題: 晶體裡的原子是怎麼排的？
  選項: [亂七八糟, 整整齊齊、一排一排, 全部擠在中間]
  答案: 1
  解說: 晶體的原子排得非常規則，就像排隊的同學，所以能讓 X 光排出整齊的光點。
- 問題: 在互動遊戲裡，原子排得越擠，光點會怎樣？
  選項: [靠得越近, 散得越開, 全部消失]
  答案: 1
  解說: 原子間距和光點間距剛好相反：原子越擠，光點散得越開。
:::
