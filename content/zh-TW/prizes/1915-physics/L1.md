## 你能量出原子有多大嗎？

:::對話 小諾 思考
我們用尺可以量鉛筆，用捲尺可以量教室。可是原子這麼小，一百萬個排起來都還不到一毫米，要怎麼量呢？
:::

1912 年，勞厄發現 X 光穿過晶體會留下漂亮的光點。可是那些光點像一團密碼，很難看懂。這時候，一對英國的父子決定一起來解開這個密碼。

## 認識今天的主角

:::對話 布拉格爸爸 預設
我是布拉格爸爸，在英國的大學當物理教授。我很會做實驗儀器！
:::

:::對話 布拉格兒子 開心
我是布拉格兒子，那時候才 22 歲，還是個研究生。我最喜歡在腦袋裡想圖形和形狀。
:::

:::對話 小晶 預設
我是食鹽晶體小晶！我身體裡有兩種原子：鈉和氯。它們排得整整齊齊，像一層一層的樓房。
:::

## 一層一層的鏡子

布拉格兒子想到一個好點子：與其把晶體想成一堆亂七八糟的光點，不如把它想成**很多層疊在一起的鏡子**。每一層原子都會反射一點點 X 光。

:::對話 小X 開心
我們 X 光一大群一起衝進晶體，有的從第一層彈回來，有的從第二層、第三層彈回來。從下面那層彈回來的，要多跑一段路才追得上！
:::

如果大家彈回來時剛好**「齊步走」**，波峰對著波峰，就會合在一起變得好亮。如果步伐對不齊，就會互相抵消，變得暗暗的。

會不會齊步，要看兩件事：**X 光射進來的角度**，還有**每層原子之間的距離**。所以只要找到「最亮的角度」，就能反過來算出原子層之間的距離，就像拿 X 光當成一把超級小的尺！

## 動手試試：讓 X 光齊步走

:::互動 bragg-law
慢慢拉動角度，看看兩道 X 光的波浪什麼時候會對齊。偵測器露出笑臉時，就是「齊步走」的角度！
:::

## 這個發現改變了什麼？

布拉格爸爸做了一台很準的儀器，可以慢慢轉動晶體、量出每個角度的 X 光有多亮。父子倆用這台儀器，第一次看清楚食鹽裡的原子是怎麼排的：

:::對話 小晶 開心
鈉和氯一個隔一個，像西洋棋盤一樣排成立體的方塊！
:::

- **原子世界的地圖**：從此，科學家可以畫出各種物質裡原子的位置，例如鑽石為什麼那麼硬。
- **找到生命的形狀**：DNA、蛋白質、很多藥物的形狀，都是用這個方法量出來的。
- **最年輕的物理學獎得主**：布拉格兒子得獎時只有 25 歲，到現在還是最年輕的諾貝爾物理學獎得主。他得知消息時，正在法國的戰場上當兵。

## 小測驗

:::測驗
- 問題: 布拉格兒子把晶體想像成什麼？
  選項: [一層一層的鏡子, 一顆大球, 一團棉花]
  答案: 0
  解說: 他把一層層原子想成會反射 X 光的鏡子，讓問題變得簡單很多。
- 問題: 從不同層彈回來的 X 光，什麼時候會變得很亮？
  選項: [步伐亂七八糟的時候, 剛好「齊步走」、波峰對波峰的時候, 晶體被打破的時候]
  答案: 1
  解說: 波峰對波峰，就會加在一起變亮，這叫做建設性干涉。
- 問題: 布拉格父子發現食鹽裡的鈉和氯怎麼排？
  選項: [全部黏成一團, 一個隔一個，像立體棋盤, 鈉在外面、氯在裡面]
  答案: 1
  解說: 鈉和氯交錯排列，每個鈉旁邊有六個氯，每個氯旁邊也有六個鈉。
:::
