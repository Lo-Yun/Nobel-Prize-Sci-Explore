## 從勞厄條件到布拉格定律

勞厄條件寫成向量形式是 **k** − **k₀** = **G**（|k| = 1/λ）。彈性散射時 |**k**| = |**k₀**|，兩者的夾角為 2θ，因此：

<div class="math">|G| = 2 sinθ / λ</div>

倒晶格向量 **G**<sub>hkl</sub> 垂直於米勒指數為 (hkl) 的晶面，長度為 n / d<sub>hkl</sub>。代入上式，就得到：

<div class="math">2 d<sub>hkl</sub> sin θ = n λ</div>

兩種描述在數學上完全等價。布拉格的「鏡面反射」圖像勝在直觀：入射角等於反射角，而每一組晶面都對應一個方向。高階反射 n 也可以改寫成間距 d/n 的「虛擬晶面」(nh nk nl) 的一階反射，這是結晶學慣用的寫法。

對立方晶系（晶格常數 a）來說：

<div class="math">d<sub>hkl</sub> = a / √(h² + k² + l²)</div>

## NaCl 與 KCl：結構因子的經典案例

岩鹽結構可以看成一個面心立方（FCC）晶格，加上兩個原子的基元：Na⁺ 位於 (0,0,0)，Cl⁻ 位於 (½,½,½)。FCC 晶格本身要求 h、k、l 全為奇數或全為偶數（奇偶混合時 F = 0），再乘上兩個離子的貢獻：

<div class="math">F<sub>hkl</sub> = 4 ( f<sub>Na</sub> + f<sub>Cl</sub> )　（h, k, l 全偶）　　F<sub>hkl</sub> = 4 ( f<sub>Na</sub> − f<sub>Cl</sub> )　（h, k, l 全奇）</div>

- **NaCl**：Na⁺ 有 10 個電子、Cl⁻ 有 18 個，f 差異明顯，所以 (111) 這類全奇數的反射雖然較弱，但看得到。
- **KCl**：K⁺ 與 Cl⁻ 都有 18 個電子，散射因子幾乎相同，全奇數的反射**幾乎消失**。因此 KCl 的繞射圖看起來像晶格常數只有一半的簡單立方。

小布拉格正是比較了 NaCl、KCl、KBr 的強度差異，才確定了離子的排列方式。這個推理和 1914 年互動元件中「第二種原子」的消光效果相同。

## 鑽石與絕對波長

1913 年，父子倆又解出了**鑽石**的結構：每個碳原子以正四面體的方式連接四個碳原子。這是凡特荷夫在 1874 年提出的「碳原子正四面體」構想，第一次得到直接的實驗證據。

要測量 X 光的**絕對波長**，需要知道 d。布拉格用 NaCl 的密度 ρ、莫耳質量 M 和亞佛加厥常數 N<sub>A</sub>，計算晶格常數：

<div class="math">a³ = 4 M / (ρ N<sub>A</sub>)　→　a ≈ 0.564 nm，　d<sub>200</sub> = a/2 ≈ 0.282 nm</div>

這讓 X 光波長和晶格常數都能用公尺來表示。此後，莫斯利利用這套方法，量測各元素特性譜線的頻率，發現頻率的平方根與原子序成線性關係（莫斯利定律），確立了原子序的物理意義。

## 小測驗

:::測驗
- 問題: 布拉格定律和勞厄條件 k − k₀ = G 的關係是什麼？
  選項: [完全等價，因為 |G| = 1/d 而且 |k − k₀| = 2 sinθ / λ, 布拉格定律只適用於單晶, 勞厄條件只適用於多色光]
  答案: 0
  解說: 彈性散射時，散射向量的大小是 2 sinθ / λ。令它等於 n / d，就得到布拉格定律。
- 問題: 立方晶系 a = 0.4 nm，(220) 晶面的間距是多少？
  選項: [0.141 nm, 0.200 nm, 0.283 nm]
  答案: 0
  解說: d = a / √(4 + 4 + 0) = 0.4 / 2.83 ≈ 0.141 nm。
- 問題: 為什麼 KCl 的全奇數反射（如 111）幾乎看不到？
  選項: [K⁺ 與 Cl⁻ 的電子數都是 18，散射因子幾乎相等，F ∝ f_K − f_Cl ≈ 0, KCl 不是晶體, KCl 會吸收所有 X 光]
  答案: 0
  解說: 全奇數反射的結構因子正比於兩種離子散射因子的差，兩者幾乎相等時就會互相抵消。
- 問題: 參與干涉的晶面數 N 增加時，布拉格峰會怎樣？
  選項: [變寬, 變窄、變尖, 位置移動]
  答案: 1
  解說: 干涉函數的主峰寬度約與 1/N 成正比；位置只由 d 和 λ 決定。
:::
