## 勞厄的光點，誰看得懂？

1912 年夏天，勞厄的繞射照片震撼了物理界。可是勞厄自己的理論解釋相當複雜：他必須假設 X 光只包含幾個特定的波長，才能說明光點的位置，這個假設後來證明是錯的。

這時，英國利茲大學的物理教授**老布拉格**，和他在劍橋大學讀研究所的兒子**小布拉格**，一起在度假時討論這張照片。老布拉格原本認為 X 光是粒子，但小布拉格回到劍橋後，想到了一個非常簡潔的解釋。

## 把晶體想成一疊鏡子

小布拉格的想法是：晶體中的原子可以看成一層層平行的{{晶面|晶體中由原子排成的平面。同一個晶體可以畫出很多組不同方向的晶面。}}。X 光照到晶面時，每一層都會像半透明的鏡子一樣，反射一小部分 X 光。

從第二層反射的 X 光，比第一層多走了一段路。只有當這段額外路程剛好是波長的整數倍時，所有層的反射光才會同相疊加，形成強烈的反射：

<div class="math">2 d sin θ = n λ　　（n = 1, 2, 3, …）</div>

- **d**：相鄰晶面的間距
- **θ**：X 光與晶面的夾角
- **λ**：X 光的波長
- **n**：整數，稱為反射的「階」

這就是**布拉格定律**。只要知道其中兩個量，就能算出第三個。

## 動手試試：布拉格反射

:::互動 bragg-law
調整入射角 θ、晶面間距 d 和波長 λ。黃色線段是第二層多走的路 2d sinθ。當它剛好等於 λ 的整數倍時，偵測器最亮。
:::

:::對話 布拉格兒子 開心
注意看：角度只要稍微偏一點，亮度就掉下去了。這是因為參與反射的晶面不只兩層，而是成千上萬層，只要有一點點不對齊，累積起來就會互相抵消。
:::

## 爸爸的儀器：X 光光譜儀

老布拉格擅長做儀器。他在 1913 年做出了**X 光光譜儀**：讓一道窄窄的 X 光打在可以轉動的晶體上，再用一個{{游離腔|X 光會讓氣體分子帶電（游離）。量測產生的電流，就能知道 X 光的強度。}}量測不同角度的反射強度。

有了這台儀器，父子倆可以雙向運用布拉格定律：

1. **已知晶體的 d，量 X 光的波長**：他們看到 X 光管除了連續的背景之外，還有幾條非常銳利的譜線，並第一次精確量出了這些金屬靶「特性譜線」的波長。
2. **已知波長，量晶體的結構**：從反射出現的角度算出 d，再比較不同晶面的強度，推出原子的位置。

:::時間軸
- 時間: 1912 年 11 月
  事件: 小布拉格在劍橋哲學學會發表「晶面反射」的解釋。
- 時間: 1913 年
  事件: 老布拉格在利茲大學完成 X 光光譜儀，父子倆解出食鹽、氯化鉀、鑽石等晶體的結構。
- 時間: 1915 年 11 月
  事件: 父子倆共同獲得諾貝爾物理學獎；小布拉格 25 歲，至今仍是最年輕的物理學獎得主。
:::

## 食鹽裡沒有「NaCl 分子」

食鹽的結構帶來了一個震撼：晶體裡**找不到一對一對的 NaCl 分子**。每個鈉離子被六個氯離子包圍，每個氯離子也被六個鈉離子包圍，兩種離子交錯排成立體的棋盤。

:::對話 小晶 開心
所以我不是「一堆 NaCl 分子」，而是一整塊巨大的離子網！
:::

有些化學家一開始很難接受這個結果，因為它挑戰了「化合物是由分子組成的」這個傳統觀念。現在我們知道，這正是**離子晶體**的特徵。

## 小測驗

:::測驗
- 問題: 布拉格定律 2d sinθ = nλ 中，2d sinθ 代表什麼？
  選項: [X 光的能量, 從相鄰兩層晶面反射的 X 光的路程差, 晶體的厚度]
  答案: 1
  解說: 第二層反射的光，進去時多走 d sinθ，出來時又多走 d sinθ，合計 2d sinθ。
- 問題: 用波長 0.154 nm 的 X 光照射晶面間距 0.282 nm 的食鹽，第一階反射大約出現在幾度？
  選項: [約 8°, 約 16°, 約 45°]
  答案: 1
  解說: sinθ = λ / 2d = 0.154 / 0.564 ≈ 0.273，θ ≈ 15.8°。
- 問題: 老布拉格的 X 光光譜儀，用什麼量測 X 光的強度？
  選項: [照相底片, 游離腔, 溫度計]
  答案: 1
  解說: X 光讓游離腔中的氣體帶電，量測電流就能比較不同角度的反射強度。
- 問題: 布拉格父子對食鹽結構的發現，為什麼讓化學家驚訝？
  選項: [晶體裡沒有一對一對的 NaCl 分子，而是交錯排列的離子, 食鹽裡含有金, 食鹽是液體]
  答案: 0
  解說: 每個離子被六個異號離子包圍，無法分辨哪個鈉屬於哪個氯。
:::
