# 網站規劃與架構

## 已確定的決策

| 項目 | 決定 |
|---|---|
| 內容範圍 | 先做「最經典的幾個」獎項。候選清單見 `classic-candidates.yaml`，最後名單由主編決定 |
| 內容產出 | Claude 起草，主編審稿。使用「文稿工作室」存放文稿，再轉成網頁 |
| 美術 | 彩色素描風格；全站嚮導是貓頭鷹「小諾」 |
| 無障礙 | 不加注音；每段都有語音朗讀（瀏覽器內建 Web Speech API） |
| 多語言 | 預留架構。目前只有繁體中文，英文的介面文字已經準備好 |
| 帳號 | 不做。學習紀錄存在讀者瀏覽器的 localStorage |
| 技術 | 用 Python 寫的靜態網站產生器（Markdown + Jinja2），文稿工作室用 Flask。互動元件用原生 JavaScript，不需要 Node.js 或打包工具 |

## 製作流程

```
 Claude 起草            主編審稿                      發佈
 content/…/L1.md  ──▶  文稿工作室 studio.py  ──▶  build.py  ──▶  _site/（靜態網頁）
                       ├ 左：編輯   右：即時預覽                      │
                       ├ 狀態：草稿 → 審稿中 → 已定稿                 ▼
                       └ 存檔前自動備份 .backup/            GitHub Pages 等主機
```

## 程式架構

```
content/<語言>/prizes/<年份-領域>/{meta.yaml, L1.md, L2.md, L3.md}
        │
        ▼
nobel_site/content.py   讀檔、front matter、狀態
nobel_site/markup.py    :::區塊 → HTML（對話、互動、小知識、時間軸、測驗、名詞解釋）
nobel_site/build.py     套用 templates/*.html，輸出 _site/
        │
        ▼
static/js/site.js       朗讀、測驗、學習紀錄、互動元件註冊 NobelIX.register()
static/js/interactives/ 每個互動元件一個檔案，頁面只會載入有用到的元件
```

## 原型（1901 物理學獎：X 光）用到的互動元件

| 程度 | 元件 | 內容 |
|---|---|---|
| L1 | `xray-lens` | X 光透視鏡：拖曳放大鏡看手、書包和小諾的內部，找出藏起來的東西 |
| L2 | `rontgen-bench` | 倫琴的實驗桌：通電、黑紙板、關燈、磁鐵，以及論文中提到的五種材料 |
| L3 | `xray-spectrum` | X 光管能譜（Kramers 定律＋鎢特性譜線）與骨／軟組織對比隨管電壓的變化（使用 NIST 衰減係數） |

## X 光接力棒系列（第一批）

| 獎項 | L1 互動 | L2 互動 | L3 互動 |
|---|---|---|---|
| 1901 物理：X 光的發現 | `xray-lens` | `rontgen-bench` | `xray-spectrum` |
| 1914 物理：晶體繞射（勞厄） | `laue-pattern`（間距、旋轉） | `laue-pattern`（加上晶格種類） | `laue-pattern`（加上結構因子與消光） |
| 1915 物理：布拉格定律 | `bragg-law`（對齊就笑臉） | `bragg-law`（路程差、d、λ） | `bragg-law`（強度掃描、實際數值） |
| 1979 醫學：電腦斷層 | `ct-shadows` | `ct-shadows` ＋ `ct-reconstruct` | `ct-reconstruct`（濾波反投影、誤差） |

## 2024 物理學獎：人工神經網路

| L1 互動 | L2 互動 | L3 互動 |
|---|---|---|
| `hopfield-memory`（塗鴉後回想）＋ `energy-ball`（球滾下山） | 加上選擇記憶與能量條 | 加上容量測試、溫度、重疊度與能量曲線；`energy-ball` 改成 Metropolis 取樣與模擬退火 |

## 2024 化學獎：蛋白質結構預測與設計

| L1 互動 | L2 互動 | L3 互動 |
|---|---|---|
| `hp-fold`（拖曳摺疊、星星計分）＋ `hp-fold design` | 加上 `coevolution`（序列排比、熱圖、接觸預測） | 基準序列與能量曲線、APC 校正、負向設計 |

系列 `ai`（AI 遇見科學）：2024 物理學獎 → 2024 化學獎。

互動元件會自動讀取頁面的程度（`data-level`），依程度顯示不同的功能。
