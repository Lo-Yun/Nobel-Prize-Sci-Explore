# 審稿清單

各篇文稿在審稿時需要特別確認的地方，集中在這裡。每一項都標出**位置**（程度 › 段落標題），可以直接在文稿工作室打開對應的頁面修改。

**使用方式**

1. 執行 `python studio.py`，點右上角「審稿清單」就能看到這份檔案（也可以直接在 GitHub 上看）。
2. 確認一項，就把 `- [ ]` 改成 `- [x]`。
3. 一篇的三個程度都審完後，在文稿工作室把狀態改成「已定稿」。
4. 全部定稿後，把 `config.yaml` 的 `show_drafts` 改成 `false`，網站就只會顯示定稿的頁面。

項目分成三類：

- **史實**：流傳很廣、但細節在不同文獻中有出入的故事或數字
- **簡化**：為了教學而簡化的模型或比喻，請確認簡化的程度可以接受
- **語氣**：涉及評價、爭議或現實議題的寫法，請確認立場和語氣
