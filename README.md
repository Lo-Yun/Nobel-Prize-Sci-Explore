# 諾貝爾科學探險

**🔗 網站：https://lo-yun.github.io/Nobel-Prize-Sci-Explore/**

把諾貝爾物理學獎、化學獎、生理學或醫學獎的研究，變成每個人都看得懂的故事。

每個獎項都用**視覺化、故事化、擬人化與互動**的方式說明，並依讀者的科學程度分成三種版本。全站由一隻戴眼鏡的貓頭鷹「小諾」擔任嚮導。

## 三種程度，同一個故事

| 程度 | 適合讀者 | 內容 |
|---|---|---|
| **L1 探險家** | 國小 | 角色對話、生活比喻、小遊戲，不用公式 |
| **L2 研究員** | 中學、自學者 | 發現的過程、原理說明、時間軸，加一點數學 |
| **L3 學者** | 大學 | 推導、實際數據、原始論文與延伸討論 |

三種程度共用相同的角色和故事主線，讀者可以隨時在頁面上切換，往深處走，或回頭複習。

## 目前內容：X 光接力棒

第一個系列從一塊發亮的螢光幕開始，追蹤 X 光如何一路接力，從神祕的新射線變成看見原子與人體內部的工具。

| 年份 | 獎項 | 主題 | 互動體驗 |
|---|---|---|---|
| 1901 | 物理學獎 | 倫琴發現 X 光 | X 光透視鏡、倫琴的實驗桌、X 光管能譜與影像對比 |
| 1914 | 物理學獎 | 勞厄：晶體的 X 光繞射 | 調整晶體的原子排列，觀察繞射光點如何變化 |
| 1915 | 物理學獎 | 布拉格父子：用 X 光分析晶體結構 | 讓 X 光「齊步走」，體驗布拉格定律 |
| 1979 | 生理學或醫學獎 | 柯馬克與杭斯菲爾德：電腦斷層掃描 | 神秘盒子解謎、從多角度投影重建切面影像 |

更多經典獎項正在籌備中。

## 網站特色

- **互動元件**：每個獎項都有可以動手操作的模擬，依程度調整難度。
- **語音朗讀**：每個段落都可以用瀏覽器內建的語音朗讀。
- **小測驗**：每篇文章最後都有測驗與解說。
- **學習紀錄**：閱讀進度與測驗成績只存在讀者自己的瀏覽器裡。不需要註冊帳號，也不會上傳任何資料。
- **科學接力棒**：每篇文章都會連到前後相關的諾貝爾獎，呈現科學發現之間的傳承。
- **手機友善**：支援手機與深色模式。

## 內容的正確性

文章中的史實與數據都附有參考資料，主要來自 [NobelPrize.org](https://www.nobelprize.org/)、得獎者的原始論文與 NIST 等公開資料。互動元件中的模擬經過簡化，以呈現原理為主，頁面上都有註明。

如果發現錯誤，歡迎[開一個 Issue](https://github.com/Lo-Yun/Nobel-Prize-Sci-Explore/issues) 告訴我們。

## 技術

網站是用 Python 產生的純靜態網頁，不需要資料庫或後端伺服器：

- **文稿**：Markdown，加上角色對話、互動元件、測驗等自訂區塊
- **產生網站**：Python（Markdown、Jinja2）
- **互動元件**：原生 JavaScript 與 SVG／Canvas，不使用前端框架
- **角色插圖**：用 Python 程式繪製的彩色素描風格 SVG
- **發佈**：GitHub Actions 自動建置，部署到 GitHub Pages
- **多語言**：已預留架構，目前提供繁體中文

在自己的電腦上執行：

```bash
pip install -r requirements.txt
python build.py        # 產生網站到 _site/
python studio.py       # 開啟文稿工作室（瀏覽器打開 http://127.0.0.1:5000）
```

文稿語法、文稿工作室的使用方式，以及新增語言的步驟，請見[編輯指南](docs/editing-guide.md)。
